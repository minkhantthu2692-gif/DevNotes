2. Description of the service

DevNotes provides tools for managing personal programming knowledge, including:

  • A Markdown lesson library with tags, search, syntax highlighting and revision history.
  • A code snippet library and a flashcard review system.
  • Import and export of your data as JSON or ZIP archives.
  • Light, dark and system themes, accent colors and typography controls.
  • Offline use — the app runs in your browser and stores data on your device.
  • Optional cloud sync across your devices, once you configure an account.
  • Optional AI assistance, once you configure it with your own API key or a deployed proxy.

The app is provided free of charge, on an “as is” and “as available” basis, whether you run it from your own copy or from a hosted deployment.
